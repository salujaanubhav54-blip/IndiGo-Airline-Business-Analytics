# IndiGo Airline Business Analytics

## Project Overview
This project is an end-to-end business analytics case study on IndiGo Airlines.
The objective is to analyze operational and financial performance and generate
data-driven insights to support better business decision-making.

## Business Problem
IndiGo operates at a large scale with high aircraft utilization. However,
operational delays, cancellations, and rising operational costs can impact
profitability and customer satisfaction. This project evaluates how operational
metrics influence financial performance.

## Dataset
The dataset represents domestic airline operations and includes:
- Route
- Aircraft type
- Passenger load and load factor
- Average delay and cancellations
- Revenue, cost, and operating profit

## Analysis Scope
The analysis focuses on:
- Route-wise profitability
- Impact of delays and cancellations on profit
- Relationship between load factor and operating margin
- Operational efficiency across aircraft types

## Tools Used
- Python (Pandas, Matplotlib)
- Excel
- Power BI

## Outcome
The project provides actionable business insights and strategic recommendations
to improve operational efficiency, cost control, and profitability.
